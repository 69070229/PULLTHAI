# PULLTHAI — FIELD RATIONS

เว็บสุ่มเมนูอาหารไทยในรูปแบบ **Gacha Pull** ได้แรงบันดาลใจจาก UI และแอนิเมชัน Headhunting ของเกม *Arknights: Endfield*
ไม่รู้จะกินอะไรดี? กดสุ่มแล้วให้ระบบเลือกมื้อนี้ให้

> โปรเจกต์รายวิชา ITF — รหัสนักศึกษา 69070229

## วิธีใช้งาน

ไม่ต้องติดตั้งอะไร เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย
(ต้องต่ออินเทอร์เน็ตเพื่อโหลดฟอนต์และรูปภาพอาหาร)

```
PULLTHAI/
├── index.html   # โครงสร้างหน้าเว็บ
├── style.css    # การตกแต่งและแอนิเมชันทั้งหมด
└── script.js    # ข้อมูลเมนู ระบบสุ่ม เสียง และคลังอาหาร
```

## ตามโจทย์ที่กำหนด

| ข้อกำหนด | สิ่งที่ทำ |
|---|---|
| Navbar ด้านบนสุด | Navbar ติดด้านบน มีโลโก้ ลิงก์ไปแต่ละส่วน ตัวนับจำนวนครั้ง/Pity/Token และปุ่มเปิดปิดเสียง |
| ส่วนแสดงผลอาหาร | แสดงรูปภาพ ชื่อเมนู (ไทย/อังกฤษ) คำอธิบาย ราคา ระดับดาว และระดับ E |
| ปุ่มสุ่ม + อาหาร ≥ 5 รายการ | ปุ่มสุ่ม ×1 และ ×10 มีเมนูอาหารไทยทั้งหมด **30 รายการ** |
| ตกแต่งให้สวยงาม | ฟอนต์จาก Google Fonts (Chakra Petch, JetBrains Mono) ปุ่มตกแต่งด้วย CSS ธีมสีดำ-เหลืองสไตล์ Endfield รูปอาหารจาก Wikimedia Commons |
| Gacha Pull Animation | แอนิเมชันสุ่มแบบ Headhunting พร้อมเสียงประกอบ |

## ฟีเจอร์

### แอนิเมชันการสุ่ม
1. เชื่อมต่อสัญญาณ — HUD และแถบโหลด
2. Supply pod ตกลงมาจากฟ้า พร้อมแถบดำแบบภาพยนตร์
3. กระแทกพื้น จอสั่น คลื่นกระแทก
4. ชาร์จพลัง — กล้องซูมเข้า ประกายไฟลอยขึ้น สีแสงบอกระดับดาว
   - ★5: สีม่วงอัปเกรดเป็นทอง + จอกลิตช์ + ป้ายเตือน `HIGH-VALUE SIGNAL`
   - ★6: ม่วง ▸ ทอง ▸ ส้ม + เสียงไซเรน + จอมืดเงียบก่อนระเบิด
5. ระเบิดแสง แล้วเปิดเผยผลลัพธ์
6. **ได้ ★6 จะโชว์เมนูนั้นเต็มจอ** กรอบหกเหลี่ยมเรืองแสง ต้องคลิกเพื่อไปต่อ

กด `SKIP` หรือ `Enter` / `Esc` เพื่อข้ามแอนิเมชันได้

### เสียงประกอบ
สังเคราะห์สดด้วย **Web Audio API** ไม่ใช้ไฟล์เสียง — เสียงบี๊บ, ลมพัด, ระเบิด, ชาร์จ, อัปเกรด, ไซเรน, เสียงดาว และคอร์ดตามระดับดาว ปิดได้ที่ปุ่ม `♪` บน Navbar

### ระบบอัตรา (อ้างอิงเกมกาชาจริง)
| ระดับ | อัตราพื้นฐาน | จำนวนเมนู |
|---|---|---|
| ★6 | 2% | 4 |
| ★5 | 8% | 6 |
| ★4 | 50% | 10 |
| ★3 | 40% | 10 |

- **Soft pity** — ไม่ได้ ★6 ติดกัน 50 ครั้ง ตั้งแต่ครั้งที่ 51 อัตรา ★6 เพิ่มครั้งละ 2% ได้แน่นอนภายใน 99 ครั้ง
- **การันตี ★5 ขึ้นไป** อย่างน้อย 1 ครั้งในทุก 10 ครั้ง
- **Rate Up 50/50** — ได้ ★6/★5 มีโอกาส 50% เป็นเมนูเรทอัปของตู้ ถ้าพลาด ครั้งถัดไปการันตี
- เฉลี่ยประมาณ 35 ครั้งต่อ ★6 (ทดสอบจำลอง 200,000 ครั้ง)

### คลังอาหารและระดับ E0–E6
- ได้เมนูครั้งแรก = **NEW!** ระดับ E0
- ได้ซ้ำจะอัปเกรด E0 ▸ E1 ▸ … ▸ E6
- ได้ซ้ำเกิน E6 แปลงเป็น Token (★3 = 1, ★4 = 2, ★5 = 5, ★6 = 10)
- เมนูที่ยังไม่ได้จะแสดงเป็น LOCKED
- บันทึกความคืบหน้าใน `localStorage` ปิดเว็บแล้วข้อมูลยังอยู่ (มีปุ่มรีเซ็ต)

### ประวัติการสุ่ม
บันทึกการสุ่มล่าสุด 60 ครั้ง พร้อมระดับดาวและผล NEW / E-tier / Token

## ปรับแต่ง

แก้ได้ที่ด้านบนของ `script.js`
- `foods` — รายการเมนู (ชื่อ คำอธิบาย ราคา ระดับดาว รูป)
- `BASE_RATE`, `SOFT_PITY`, `PITY5` — อัตราและระบบ pity
- `RATE_UP`, `BANNER_NAME` — เมนูเรทอัปและชื่อตู้
